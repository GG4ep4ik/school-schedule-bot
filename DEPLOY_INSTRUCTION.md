## ЭТАП 1: ПОДГОТОВКА К ДЕПЛОЮ

### ✅ Что вам понадобится:

#### 1. Токен Telegram-бота

**Если у вас ещё НЕТ бота:**

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте команду: `/newbot`
4. Придумайте название (например: "Школьное расписание")
5. Придумайте username (должен заканчиваться на `bot`, например: `my_school_schedule_bot`)
6. **Скопируйте токен** - это длинная строка вроде: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
7. ⚠️ **ВАЖНО**: Сохраните токен в надёжное место - он понадобится!

**Если бот уже создан, но токен потерян:**

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте: `/mybots`
3. Выберите вашего бота
4. Нажмите `API Token`
5. Скопируйте токен

#### 2. Настройка Google Sheets (если используете Google Таблицы)

**Если вы используете Excel файл - пропустите этот пункт!**

##### 2.1. Создание проекта в Google Cloud

1. Перейдите: https://console.cloud.google.com/
2. Нажмите **"Select a project"** (вверху)
3. Нажмите **"New Project"**
4. Введите название: `School Bot` (или любое другое)
5. Нажмите **"Create"** и подождите ~10 секунд

##### 2.2. Включение API

1. В меню слева: **"APIs & Services"** → **"Library"**
2. В поиске введите: `Google Sheets API`
3. Нажмите на результат → **"Enable"**
4. Вернитесь назад, в поиске введите: `Google Drive API`
5. Нажмите на результат → **"Enable"**

##### 2.3. Создание Service Account

1. В меню слева: **"APIs & Services"** → **"Credentials"**
2. Нажмите **"Create Credentials"** → **"Service Account"**
3. Заполните:
   - **Service account name**: `schedule-bot`
   - Нажмите **"Create and Continue"**
4. На втором шаге нажмите **"Continue"** (ничего не заполняя)
5. На третьем шаге нажмите **"Done"**

##### 2.4. Скачивание ключа

1. На странице "Credentials" найдите созданный Service Account
2. Нажмите на email (выглядит как `schedule-bot@...iam.gserviceaccount.com`)
3. **ВАЖНО**: Скопируйте этот email в блокнот!
4. Перейдите на вкладку **"Keys"**
5. Нажмите **"Add Key"** → **"Create new key"**
6. Выберите тип **JSON**
7. Нажмите **"Create"**
8. Файл `credentials.json` автоматически скачается на ваш компьютер
9. Запомните, где он находится!

##### 2.5. Предоставление доступа к таблице

1. Откройте вашу Google Таблицу с расписанием
2. Нажмите кнопку **"Share"** (Поделиться) вверху справа
3. Вставьте email сервисного аккаунта (из пункта 2.4, шаг 3)
4. Установите права: **"Viewer"** (Читатель)
5. **Снимите галочку** "Notify people"
6. Нажмите **"Share"**

##### 2.6. Получение ID таблицы

1. Откройте вашу Google Таблицу
2. Посмотрите на адресную строку браузера:
   ```
   https://docs.google.com/spreadsheets/d/1ABC123xyz456DEF/edit
                                          ^^^^^^^^^^^^^^^^^^^^
                                          Это и есть ваш ID
   ```
3. Скопируйте ID в блокнот

#### 3. Подготовка Excel файла (если используете локальный файл)

**Если вы используете Google Sheets - пропустите этот пункт!**

1. Убедитесь, что файл называется `Расписание.xlsx`
2. Файл должен быть в формате Excel (.xlsx)
3. Держите файл под рукой - его нужно будет загрузить на хостинг

## ЭТАП 3: СОЗДАНИЕ ПРОЕКТА НА BOTHOST

### СПОСОБ 1: Через веб-интерфейс (РЕКОМЕНДУЕТСЯ)

Этот способ проще для начинающих!

#### Шаг 1: Создание нового проекта

1. После входа нажмите **"Create New Project"** или **"Создать проект"**
2. Заполните форму:
   - **Название проекта**: `school-schedule-bot` (или любое другое)
   - **Тип**: выберите **"Python"**
   - **Версия Python**: выберите **"3.11"** или **"3.10"**
3. Нажмите **"Create"** или **"Создать"**

#### Шаг 2: Загрузка файлов проекта

**Вариант 2.1: Через ZIP архив (самый простой)**

1. На вашем компьютере откройте папку `deploy_bothost`
2. Выделите ВСЕ файлы и папки (кроме `data/`)
3. **Windows**: Правой кнопкой → Отправить → Сжатая ZIP-папка
4. **Mac**: Правой кнопкой → Сжать
5. Назовите архив `bot.zip`
6. В панели BotHost найдите раздел **"Upload Files"** или **"Загрузить файлы"**
7. Перетащите `bot.zip` или нажмите **"Browse"** и выберите файл
8. Дождитесь окончания загрузки
9. Нажмите **"Extract"** или **"Распаковать"**

**Вариант 2.2: Загрузка файлов по одному**

1. В панели BotHost найдите **"File Manager"** или **"Файловый менеджер"**
2. Загрузите следующие файлы по очереди:
   - `bot.py`
   - `config.py`
   - `database.py`
   - `scheduler.py`
   - `sheets_service.py`
   - `local_sheets_service.py`
   - `requirements.txt`
   - `Procfile`
   - `runtime.txt`
3. Создайте папку `handlers`:
   - Нажмите **"New Folder"** → введите `handlers`
4. Откройте папку `handlers` и загрузите:
   - `__init__.py`
   - `common.py`
5. Создайте папку `data` (пустая, для базы данных)

#### Шаг 3: Установка зависимостей

BotHost обычно устанавливает зависимости автоматически из `requirements.txt`.

Если этого не произошло:

1. Найдите раздел **"Console"** или **"Terminal"**
2. Введите команду:
   ```bash
   pip install -r requirements.txt
   ```
3. Дождитесь завершения установки

### СПОСОБ 2: Через Git/GitHub

Этот способ удобнее для тех, кто знаком с Git.

#### Шаг 1: Создание репозитория на GitHub

1. Откройте: https://github.com/
2. Войдите в аккаунт (или создайте новый)
3. Нажмите **"New repository"** (зелёная кнопка)
4. Заполните:
   - **Repository name**: `school-schedule-bot`
   - **Visibility**: можно **Private** (приватный)
   - Не ставьте галочки на README, .gitignore и License
5. Нажмите **"Create repository"**

#### Шаг 2: Загрузка кода в репозиторий

**Способ A: Через веб-интерфейс GitHub (проще)**

1. На странице созданного репозитория нажмите **"uploading an existing file"**
2. Перетащите ВСЕ файлы из папки `deploy_bothost` (кроме `data/`)
3. Внизу страницы введите описание: `Initial commit`
4. Нажмите **"Commit changes"**

**Способ B: Через командную строку (для опытных)**

1. Откройте командную строку или терминал
2. Перейдите в папку `deploy_bothost`:
   ```bash
   cd путь/к/папке/deploy_bothost
   ```
3. Выполните команды:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_USERNAME/school-schedule-bot.git
   git push -u origin main
   ```

#### Шаг 3: Подключение GitHub к BotHost

1. В панели BotHost нажмите **"Create New Project"**
2. Выберите **"Import from Git"** или **"Импорт из Git"**
3. Вставьте URL репозитория: `https://github.com/ВАШ_USERNAME/school-schedule-bot`
4. Если репозиторий приватный:
   - Нажмите **"Add Deploy Key"**
   - Скопируйте предложенный SSH ключ
   - Откройте GitHub → Settings → Deploy keys → Add deploy key
   - Вставьте ключ, поставьте галочку "Allow write access"
   - Нажмите "Add key"
5. Вернитесь в BotHost и нажмите **"Deploy"**

## ЭТАП 4: НАСТРОЙКА ПЕРЕМЕННЫХ ОКРУЖЕНИЯ

Переменные окружения - это настройки бота, которые хранятся отдельно от кода.

### Шаг 1: Открытие настроек

1. В панели BotHost откройте ваш проект
2. Найдите раздел **"Environment Variables"** или **"Переменные окружения"**
   - Может называться: **"Config Vars"**, **"Settings"**, **"Environment"**

### Шаг 2: Добавление переменных

Нажимайте **"Add Variable"** или **"Добавить переменную"** и вводите:

#### Обязательные переменные:

**1. TELEGRAM_BOT_TOKEN**
```
Имя: TELEGRAM_BOT_TOKEN
Значение: ваш_токен_от_BotFather
```
Пример значения: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

**2. USE_LOCAL_FILE**
```
Имя: USE_LOCAL_FILE
Значение: false (если используете Google Sheets)
         или
         true (если используете Excel файл)
```

#### Если USE_LOCAL_FILE=false (Google Sheets):

**3. SPREADSHEET_ID**
```
Имя: SPREADSHEET_ID
Значение: ID_вашей_таблицы
```
Пример: `1CfK74tzLoIz_0YXZeCZqHI6suvFLKp9FtiSf-GGVFjY`

**4. SHEET_NAME**
```
Имя: SHEET_NAME
Значение: Расписание
```
(или как называется лист в вашей таблице)

#### Если USE_LOCAL_FILE=true (Excel):

**3. LOCAL_SCHEDULE_FILE**
```
Имя: LOCAL_SCHEDULE_FILE
Значение: Расписание.xlsx
```

#### Опциональные переменные:

**5. CHECK_INTERVAL_MINUTES** (рекомендуется)
```
Имя: CHECK_INTERVAL_MINUTES
Значение: 5
```
Частота проверки изменений в минутах (5-10 оптимально)

### Шаг 3: Сохранение

Нажмите **"Save"** или **"Сохранить"**

## ЭТАП 5: ЗАГРУЗКА CREDENTIALS.JSON

**Этот шаг ТОЛЬКО для Google Sheets! Если используете Excel - пропустите.**

### Способ 1: Через File Manager (проще)

1. В панели BotHost откройте **"File Manager"**
2. Убедитесь, что вы в корневой папке проекта
3. Найдите кнопку **"Upload"** или **"Загрузить"**
4. Выберите файл `credentials.json` с вашего компьютера
5. Дождитесь загрузки
6. Убедитесь, что файл появился в списке

### Способ 2: Через переменные окружения (сложнее, но безопаснее)

1. Откройте `credentials.json` в блокноте или текстовом редакторе
2. Скопируйте **ВЕСЬ** текст файла (он в формате JSON)
3. В панели BotHost добавьте переменную:
   ```
   Имя: GOOGLE_CREDENTIALS_JSON
   Значение: [вставьте скопированный текст]
   ```
4. Измените файл `sheets_service.py` на хостинге:
   - Найдите строку с `CREDENTIALS_FILE`
   - Добавьте код для чтения из переменной окружения

Этот способ безопаснее, но требует небольших изменений в коде. Если не уверены - используйте Способ 1.

## РЕШЕНИЕ ВОЗМОЖНЫХ ПРОБЛЕМ

### Проблема 1: "Бот не запускается" / Статус "Error"

**Причина**: Ошибка в коде или конфигурации

**Решение:**

1. Откройте **"Logs"** и найдите строку с ошибкой (обычно последняя, красным цветом)

2. **Ошибка**: `credentials.json not found` или `FileNotFoundError: credentials.json`
   - **Причина**: Файл credentials.json не загружен
   - **Решение**: 
     - Проверьте, что файл есть в File Manager
     - Убедитесь, что USE_LOCAL_FILE=false
     - Если файла нет - загрузите (см. Этап 5)

3. **Ошибка**: `SPREADSHEET_ID not found` или `SPREADSHEET_ID не указан`
   - **Причина**: Не установлена переменная SPREADSHEET_ID
   - **Решение**: Добавьте переменную в Environment Variables (см. Этап 4)

4. **Ошибка**: `Access denied` или `Permission denied` или `403`
   - **Причина**: Service Account не имеет доступа к таблице
   - **Решение**:
     - Откройте Google Таблицу
     - Нажмите "Share"
     - Убедитесь, что email сервисного аккаунта есть в списке
     - Если нет - добавьте его с правами "Viewer"

5. **Ошибка**: `Invalid token` или `Unauthorized`
   - **Причина**: Неправильный токен бота
   - **Решение**:
     - Откройте @BotFather → /mybots → выберите бота → API Token
     - Скопируйте токен заново
     - Обновите переменную TELEGRAM_BOT_TOKEN

6. **Ошибка**: `ModuleNotFoundError: No module named 'aiogram'` или другой модуль
   - **Причина**: Зависимости не установлены
   - **Решение**:
     - Откройте Console/Terminal в BotHost
     - Выполните: `pip install -r requirements.txt`
     - Перезапустите бота

7. **Ошибка**: `Local file not found` или `Расписание.xlsx не найден`
   - **Причина**: Excel файл не загружен
   - **Решение**:
     - Убедитесь, что USE_LOCAL_FILE=true
     - Загрузите файл `Расписание.xlsx` через File Manager
     - Проверьте правильность имени файла

### Проблема 2: "Бот запущен, но не отвечает"

**Решение:**

1. Проверьте статус в панели BotHost - должен быть "Running"
2. Проверьте логи - не должно быть ошибок
3. Убедитесь, что вы ищете правильного бота в Telegram (проверьте username)
4. Попробуйте:
   - Нажать /start
   - Написать любое сообщение
   - Подождать 1-2 минуты
5. Перезапустите бота:
   - Нажмите "Stop" в панели BotHost
   - Подождите 10 секунд
   - Нажмите "Start"

### Проблема 3: "Бот показывает старое расписание"

**Причина**: Кэш или интервал проверки

**Решение:**

1. Подождите 5-10 минут (по умолчанию интервал проверки 5 минут)
2. Если не помогло:
   - Проверьте, что изменения действительно сохранены в Google Таблице
   - Убедитесь, что вы изменили правильный лист (SHEET_NAME)
3. Перезапустите бота (Stop → Start)

### Проблема 4: "База данных не сохраняется" / "Пользователи теряют свой класс"

**Причина**: Файловая система хостинга временная (ephemeral storage)

**Решение:**

Некоторые хостинги не сохраняют файлы при перезапуске. Варианты:

1. **Подключить Persistent Storage** (если доступно):
   - В панели BotHost найдите "Volumes" или "Storage"
   - Создайте volume и примонтируйте к папке `/app/data`

2. **Использовать внешнюю БД** (для продвинутых):
   - PostgreSQL, MySQL или MongoDB
   - Потребует изменений в коде

3. **Выбрать другой хостинг**:
   - Railway.app
   - Render.com
   - VPS (DigitalOcean, Vultr)

### Проблема 5: "Слишком много запросов" / "Quota exceeded"

**Причина**: Превышен лимит запросов к Google Sheets API

**Решение:**

1. Увеличьте CHECK_INTERVAL_MINUTES до 10-15 минут
2. Ограничьте количество пользователей (если их очень много)
3. Перейдите на локальный Excel файл (USE_LOCAL_FILE=true)

### Проблема 6: "Сайт BotHost недоступен"

**Решение:**

Используйте альтернативные хостинги:

#### Railway.app (рекомендуется)

1. Зарегистрируйтесь: https://railway.app/
2. Нажмите "New Project" → "Deploy from GitHub repo"
3. Подключите GitHub и выберите репозиторий
4. Railway автоматически определит Python
5. Добавьте переменные окружения в разделе "Variables"
6. Загрузите credentials.json через "Volume" или переменные

#### Render.com

1. Зарегистрируйтесь: https://render.com/
2. Нажмите "New +" → "Background Worker"
3. Подключите GitHub репозиторий
4. Build Command: `pip install -r requirements.txt`

## КАК ИЗМЕНИТЬ ОТСЛЕЖИВАЕМУЮ ТАБЛИЦУ

Если вы хотите, чтобы бот следил за другой Google Таблицей:

### Вариант 1: Изменить существующую таблицу (проще)

1. Скопируйте ID новой таблицы из URL
2. В панели BotHost откройте "Environment Variables"
3. Найдите переменную `SPREADSHEET_ID`
4. Нажмите "Edit" или значок карандаша
5. Вставьте новый ID
6. Нажмите "Save"
7. **ВАЖНО**: Не забудьте дать доступ Service Account к новой таблице!
   - Откройте новую таблицу
   - Share → вставьте email сервисного аккаунта
   - Права: Viewer
8. Перезапустите бота (Stop → Start)

### Вариант 2: Создать новый Service Account (безопаснее)

Используйте, если таблица принадлежит другому аккаунту:

1. Повторите Этап 1, пункты 2.1-2.6 для новой таблицы
2. Скачайте новый `credentials.json`
3. Замените старый файл на хостинге:
   - Удалите старый `credentials.json`
   - Загрузите новый
4. Обновите `SPREADSHEET_ID` (см. Вариант 1)
5. Перезапустите бота

### Вариант 3: Переключиться с Google Sheets на Excel

1. Подготовьте файл `Расписание.xlsx`
2. В панели BotHost:
   - Откройте File Manager
   - Загрузите `Расписание.xlsx`
3. Откройте Environment Variables
4. Измените `USE_LOCAL_FILE` на `true`
5. Можете удалить переменные `SPREADSHEET_ID` и `SHEET_NAME` (необязательно)
6. Перезапустите бота

### Вариант 4: Переключиться с Excel на Google Sheets

1. Создайте и настройте Google Таблицу (Этап 1, пункт 2)
2. Загрузите `credentials.json` на хостинг
3. В Environment Variables:
   - Измените `USE_LOCAL_FILE` на `false`
   - Добавьте `SPREADSHEET_ID`
   - Добавьте `SHEET_NAME` (если отличается от "Расписание")
4. Перезапустите бота

### Проверка после изменения таблицы

1. Откройте логи - должно быть:
   ```
   INFO - ✅ Подключение к Google Sheets успешно. Найдено классов: X
   INFO - 📚 Доступные классы: 10А, 10Б, 11А...
   ```
2. Отправьте боту `/start` - он должен показать новые классы
