## ЭТАП 1: ПОДГОТОВКА К ДЕПЛОЮ

### ✅ Что вам понадобится:

#### 1. Токен Telegram-бота

**Если у вас ещё НЕТ бота:**

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте команду: `/newbot`
4. Придумайте название (например: "Школьное расписание")
5. Придумайте username (должен заканчиваться на `bot`, например: `my_school_schedule_bot`)
6. **Скопируйте токен** - это длинная строка вроде: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
7. ⚠️ **ВАЖНО**: Сохраните токен в надёжное место - он понадобится!

**Если бот уже создан, но токен потерян:**

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте: `/mybots`
3. Выберите вашего бота
4. Нажмите `API Token`
5. Скопируйте токен

#### 2. Настройка Google Sheets (если используете Google Таблицы)

**Если вы используете Excel файл - пропустите этот пункт!**

##### 2.1. Создание проекта в Google Cloud

1. Перейдите: https://console.cloud.google.com/
2. Нажмите **"Select a project"** (вверху)
3. Нажмите **"New Project"**
4. Введите название: `School Bot` (или любое другое)
5. Нажмите **"Create"** и подождите ~10 секунд

##### 2.2. Включение API

1. В меню слева: **"APIs & Services"** → **"Library"**
2. В поиске введите: `Google Sheets API`
3. Нажмите на результат → **"Enable"**
4. Вернитесь назад, в поиске введите: `Google Drive API`
5. Нажмите на результат → **"Enable"**

##### 2.3. Создание Service Account

1. В меню слева: **"APIs & Services"** → **"Credentials"**
2. Нажмите **"Create Credentials"** → **"Service Account"**
3. Заполните:
   - **Service account name**: `schedule-bot`
   - Нажмите **"Create and Continue"**
4. На втором шаге нажмите **"Continue"** (ничего не заполняя)
5. На третьем шаге нажмите **"Done"**

##### 2.4. Скачивание ключа

1. На странице "Credentials" найдите созданный Service Account
2. Нажмите на email (выглядит как `schedule-bot@...iam.gserviceaccount.com`)
3. **ВАЖНО**: Скопируйте этот email в блокнот!
4. Перейдите на вкладку **"Keys"**
5. Нажмите **"Add Key"** → **"Create new key"**
6. Выберите тип **JSON**
7. Нажмите **"Create"**
8. Файл `credentials.json` автоматически скачается на ваш компьютер
9. Запомните, где он находится!

##### 2.5. Предоставление доступа к таблице

1. Откройте вашу Google Таблицу с расписанием
2. Нажмите кнопку **"Share"** (Поделиться) вверху справа
3. Вставьте email сервисного аккаунта (из пункта 2.4, шаг 3)
4. Установите права: **"Viewer"** (Читатель)
5. **Снимите галочку** "Notify people"
6. Нажмите **"Share"**

##### 2.6. Получение ID таблицы

1. Откройте вашу Google Таблицу
2. Посмотрите на адресную строку браузера:
   ```
   https://docs.google.com/spreadsheets/d/1ABC123xyz456DEF/edit
                                          ^^^^^^^^^^^^^^^^^^^^
                                          Это и есть ваш ID
   ```
3. Скопируйте ID в блокнот

#### 3. Подготовка Excel файла (если используете локальный файл)

**Если вы используете Google Sheets - пропустите этот пункт!**

1. Убедитесь, что файл называется `Расписание.xlsx`
2. Файл должен быть в формате Excel (.xlsx)
3. Держите файл под рукой - его нужно будет загрузить на хостинг

## ЭТАП 3: СОЗДАНИЕ БОТА НА BOTHOST

У BotHost.ru есть 2 способа загрузки кода. Рекомендую **Способ 1 (GitHub)** - он удобнее для обновлений.

---

### СПОСОБ 1: Через GitHub (РЕКОМЕНДУЕТСЯ)

Этот способ удобнее - при обновлении кода на GitHub бот автоматически обновится на хостинге.

#### Шаг 1: Создание репозитория на GitHub

1. Откройте: https://github.com/
2. Войдите в аккаунт (или создайте новый - это бесплатно)
3. Нажмите **"New repository"** (зелёная кнопка или + в правом верхнем углу)
4. Заполните:
   - **Repository name**: `school-schedule-bot`
   - **Visibility**: выберите **Private** (приватный) - так безопаснее
   - ❌ НЕ ставьте галочки на README, .gitignore и License
5. Нажмите **"Create repository"**

#### Шаг 2: Загрузка кода в GitHub

**Способ A: Через веб-интерфейс GitHub (проще для начинающих)**

1. На странице созданного репозитория найдите ссылку **"uploading an existing file"**
2. Откройте папку `deploy_bothost` на вашем компьютере
3. Выделите **ВСЕ файлы и папки** (кроме `data/`)
   - Зажмите Ctrl+A (Windows) или Cmd+A (Mac)
4. Перетащите их в окно браузера на GitHub
5. Внизу страницы в поле "Commit changes" введите: `Первая загрузка бота`
6. Нажмите **"Commit changes"**
7. Подождите 10-20 секунд пока файлы загрузятся

**Способ B: Через Git командную строку (для опытных)**

⚠️ Требует установленного Git на компьютере

1. Откройте командную строку (Windows) или терминал (Mac/Linux)
2. Перейдите в папку `deploy_bothost`:
   ```bash
   cd путь\к\папке\deploy_bothost
   ```
   Например: `cd C:\проекты\school_schedule_bot1\deploy_bothost`

3. Выполните команды по очереди:
   ```bash
   git init
   git add .
   git commit -m "Первая загрузка бота"
   git branch -M main
   git remote add origin https://github.com/ВАШ_USERNAME/school-schedule-bot.git
   git push -u origin main
   ```

4. Введите логин и пароль GitHub когда попросит

#### Шаг 3: Подключение GitHub к BotHost.ru

1. Вернитесь на сайт https://bothost.ru/
2. В личном кабинете нажмите **"Создать бота"** или **"Добавить бота"**
3. Выберите **"Подключить через Git"** или **"GitHub"**
4. BotHost попросит доступ к вашему GitHub:
   - Нажмите **"Авторизовать"**
   - Выберите репозиторий `school-schedule-bot`
   - Или введите URL: `https://github.com/ВАШ_USERNAME/school-schedule-bot`
5. Выберите ветку: **main** (или master)
6. BotHost автоматически определит, что это Python проект
7. Нажмите **"Создать"** или **"Deploy"**

#### Шаг 4: Настройка автоматического деплоя

✅ **Готово!** Теперь при каждом обновлении кода в GitHub:
- BotHost автоматически заметит изменения
- Пересоберёт бота
- Перезапустит его

---

### СПОСОБ 2: Через веб-интерфейс (загрузка файлов)

Этот способ проще, но при обновлениях придётся загружать файлы заново.

#### Шаг 1: Создание бота

1. В личном кабинете BotHost.ru нажмите **"Создать бота"**
2. Выберите **"Загрузить файлы"** или **"Вручную"**
3. Введите название бота: `school-schedule-bot`

#### Шаг 2: Создание ZIP архива

1. Откройте папку `deploy_bothost` на вашем компьютере
2. Выделите **ВСЕ файлы и папки** (кроме `data/`)
3. **Windows**: 
   - Правой кнопкой → Отправить → Сжатая ZIP-папка
4. **Mac**: 
   - Правой кнопкой → Сжать
5. Назовите архив: `bot.zip`

#### Шаг 3: Загрузка архива

1. На странице создания бота найдите поле загрузки файлов
2. Нажмите **"Выбрать файл"** или перетащите `bot.zip`
3. Дождитесь загрузки (может занять 1-2 минуты)
4. BotHost автоматически распакует архив и определит Python

#### Шаг 4: Проверка файлов

1. После загрузки откройте **"Файловый менеджер"** или **"Files"**
2. Убедитесь, что структура правильная:
   ```
   /
   ├── bot.py
   ├── config.py
   ├── database.py
   ├── scheduler.py
   ├── sheets_service.py
   ├── local_sheets_service.py
   ├── handlers/
   │   ├── __init__.py
   │   └── common.py
   ├── requirements.txt
   ├── Procfile
   └── runtime.txt
   ```

## ЭТАП 4: НАСТРОЙКА ПЕРЕМЕННЫХ ОКРУЖЕНИЯ

Переменные окружения - это настройки бота (токены, ID таблиц), которые хранятся отдельно от кода.

### Шаг 1: Открытие настроек

1. В панели BotHost.ru откройте вашего бота
2. Найдите раздел **"Переменные окружения"** или **"Environment Variables"** или **"Настройки"**

### Шаг 2: Добавление переменных

Нажимайте **"Добавить переменную"** и вводите по очереди:

#### Обязательные переменные:

**1. TELEGRAM_BOT_TOKEN**
```
Имя: TELEGRAM_BOT_TOKEN
Значение: ваш_токен_от_BotFather
```
Пример: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

**2. USE_LOCAL_FILE**
```
Имя: USE_LOCAL_FILE
Значение: false
```
- `false` = используем Google Sheets
- `true` = используем Excel файл

#### Если USE_LOCAL_FILE=false (Google Sheets):

**3. SPREADSHEET_ID**
```
Имя: SPREADSHEET_ID
Значение: ID_вашей_Google_таблицы
```
Пример: `1CfK74tzLoIz_0YXZeCZqHI6suvFLKp9FtiSf-GGVFjY`

**4. SHEET_NAME**
```
Имя: SHEET_NAME
Значение: Расписание
```
(или как называется лист в вашей таблице)

#### Если USE_LOCAL_FILE=true (Excel):

**3. LOCAL_SCHEDULE_FILE**
```
Имя: LOCAL_SCHEDULE_FILE
Значение: Расписание.xlsx
```

#### Опциональная переменная (рекомендуется):

**CHECK_INTERVAL_MINUTES**
```
Имя: CHECK_INTERVAL_MINUTES
Значение: 5
```
Как часто проверять изменения (в минутах). 5-10 - оптимально.

### Шаг 3: Сохранение

Нажмите **"Сохранить"** или **"Save"**

## ЭТАП 5: ЗАГРУЗКА CREDENTIALS.JSON

**⚠️ Этот шаг ТОЛЬКО для Google Sheets! Если используете Excel - пропустите.**

### Способ 1: Через файловый менеджер (проще)

1. В панели BotHost.ru откройте вашего бота
2. Найдите **"Файловый менеджер"** или **"Files"**
3. Убедитесь, что вы в корневой папке (не в подпапке)
4. Нажмите **"Загрузить файл"** или **"Upload"**
5. Выберите файл `credentials.json` с вашего компьютера
6. Дождитесь загрузки
7. Убедитесь, что файл появился в корне проекта:
   ```
   /credentials.json  ← должен быть здесь
   ```

### Способ 2: Через переменные окружения (сложнее, но безопаснее)

⚠️ Требует небольших изменений в коде

1. Откройте `credentials.json` в блокноте
2. Скопируйте **ВЕСЬ** текст (это JSON)
3. В BotHost.ru добавьте переменную:
   ```
   Имя: GOOGLE_CREDENTIALS_JSON
   Значение: [вставьте скопированный JSON текст]
   ```
4. В файле `sheets_service.py` нужно будет добавить код для чтения из переменной окружения

Если не уверены - используйте **Способ 1**.

## ЭТАП 6: ЗАПУСК БОТА

## РЕШЕНИЕ ВОЗМОЖНЫХ ПРОБЛЕМ

### Проблема 1: "Бот не запускается" / Статус "Error"

**Проверьте логи** - там написано, в чём проблема.

#### Ошибка: `credentials.json not found`

```
FileNotFoundError: credentials.json
```

**Причина**: Файл credentials.json не загружен

**Решение**: 
1. Убедитесь, что `USE_LOCAL_FILE=false`
2. Откройте файловый менеджер
3. Проверьте наличие `credentials.json` в корне
4. Если нет - загрузите (см. Этап 5)

---

#### Ошибка: `SPREADSHEET_ID not found`

```
SPREADSHEET_ID не указан в .env файле!
```

**Причина**: Не установлена переменная окружения SPREADSHEET_ID

**Решение**:
1. Откройте переменные окружения
2. Добавьте переменную `SPREADSHEET_ID`
3. Значение = ID вашей таблицы из URL
4. Сохраните и перезапустите бота

---

#### Ошибка: `Access denied` / `Permission denied` / `403`

```
gspread.exceptions.APIError: 403 Forbidden
```

**Причина**: Service Account не имеет доступа к таблице

**Решение**:
1. Откройте вашу Google Таблицу
2. Нажмите **"Share"** (Поделиться)
3. Проверьте список - есть ли там email вроде `schedule-bot@...iam.gserviceaccount.com`
4. Если нет:
   - Нажмите "Share"
   - Вставьте email из credentials.json
   - Права: **Viewer** (Читатель)
   - Нажмите "Share"
5. Перезапустите бота на BotHost.ru

---

#### Ошибка: `Invalid token` / `Unauthorized`

```
aiogram.exceptions.TelegramUnauthorizedError: Unauthorized
```

**Причина**: Неправильный токен бота

**Решение**:
1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots`
3. Выберите бота → API Token
4. Скопируйте токен
5. В BotHost.ru откройте переменные окружения
6. Измените `TELEGRAM_BOT_TOKEN` на правильный
7. Сохраните и перезапустите

---

#### Ошибка: `ModuleNotFoundError`

```
ModuleNotFoundError: No module named 'aiogram'
```

**Причина**: Зависимости не установились

**Решение**:
1. Проверьте, что файл `requirements.txt` загружен
2. В логах найдите этап установки зависимостей
3. Если видите ошибки при установке - напишите в поддержку BotHost
4. Попробуйте перезапустить бота

---

#### Ошибка: `Local file not found`

```
Local file not found: Расписание.xlsx
```

**Причина**: Excel файл не загружен (если USE_LOCAL_FILE=true)

**Решение**:
1. Откройте файловый менеджер
2. Загрузите файл `Расписание.xlsx` в корень проекта
3. Перезапустите бота

### Проблема 2: "Бот запущен, но не отвечает"

**Решение:**

1. **Проверьте статус** - должен быть "Работает" / "Running"
2. **Проверьте логи** - не должно быть ошибок красным
3. **Убедитесь в правильности username** бота в Telegram
4. Попробуйте:
   - Написать боту `/start`
   - Подождать 1-2 минуты
   - Отправить любое сообщение
5. **Перезапустите бота**:
   - В панели BotHost нажмите "Остановить"
   - Подождите 10 секунд
   - Нажмите "Запустить"

---

### Проблема 3: "Бот показывает старое расписание"

**Причина**: Кэш или интервал проверки

**Решение:**

1. Подождите время, указанное в `CHECK_INTERVAL_MINUTES` (по умолчанию 5 минут)
2. Убедитесь, что изменения сохранены в Google Таблице
3. Проверьте правильность `SHEET_NAME`
4. Перезапустите бота через панель BotHost

---

### Проблема 4: "База данных теряется / Пользователи забывают класс"

**Причина**: Вы на бесплатном тарифе Starter

⚠️ На тарифе **Starter (бесплатно)** хранилище временное - база стирается при перезапуске!

**Решение:**

Перейдите на тариф **Basic (99₽/мес)** или выше:
1. В панели BotHost откройте "Тарифы"
2. Выберите Basic
3. Оплатите 99₽
4. Теперь база данных будет сохраняться постоянно

---

### Проблема 5: "Quota exceeded" / "Слишком много запросов"

```
gspread.exceptions.APIError: Quota exceeded
```

**Причина**: Превышен лимит запросов к Google Sheets API

**Решение:**

1. Увеличьте `CHECK_INTERVAL_MINUTES` до 10-15 минут
2. Или перейдите на локальный Excel файл:
   - Установите `USE_LOCAL_FILE=true`
   - Загрузите `Расписание.xlsx`
   - Перезапустите бота

---

### Проблема 6: "Out of memory" / Нехватка памяти

**Причина**: Недостаточно RAM (возможно на тарифе Starter)

**Решение:**

1. Перейдите на тариф Basic или Pro (больше памяти)
2. Или оптимизируйте код (для продвинутых)

---

### Проблема 7: Ошибки при автоматическом деплое через GitHub

**Причина**: BotHost не может получить код из GitHub

**Решение:**

1. Проверьте, что репозиторий доступен
2. Если репозиторий Private:
   - Убедитесь, что BotHost авторизован
   - Проверьте Settings → Integrations в GitHub
3. Проверьте правильность ветки (main или master)
4. Попробуйте переподключить репозиторий
