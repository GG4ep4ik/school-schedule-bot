## 🔑 Данные для деплоя

### Обязательно:
- [ ] Токен Telegram-бота от @BotFather
- [ ] Выбран источник данных (Google Sheets ИЛИ Excel)

### Если Google Sheets:
- [ ] Создан проект в Google Cloud
- [ ] Включены Google Sheets API и Drive API
- [ ] Создан Service Account
- [ ] Скачан credentials.json
- [ ] Email Service Account добавлен в доступ к таблице
- [ ] Получен SPREADSHEET_ID из URL таблицы
- [ ] Известно имя листа (SHEET_NAME)

### Если Excel:
- [ ] Подготовлен файл Расписание.xlsx
- [ ] Файл в правильном формате (.xlsx)
- [ ] Структура таблицы соответствует требованиям

## 🌐 Хостинг

- [ ] Выбрана платформа (BotHost / Railway / Render / VPS)
- [ ] Создан аккаунт на платформе
- [ ] Понятно, как загружать файлы
- [ ] Понятно, как настраивать переменные окружения

## ⚙️ Переменные окружения

Подготовьте значения:

```
TELEGRAM_BOT_TOKEN=________________
USE_LOCAL_FILE=________ (true/false)
SPREADSHEET_ID=________________ (если Sheets)
SHEET_NAME=________________ (если Sheets)
CHECK_INTERVAL_MINUTES=5
```

## ✅ Финальная проверка
