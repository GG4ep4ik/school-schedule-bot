## 📁 ЧТО В ЭТОЙ ПАПКЕ?

### 🔧 Файлы бота (основные):
- **bot.py** - главный файл запуска
- **config.py** - настройки
- **database.py** - работа с базой данных
- **scheduler.py** - мониторинг изменений
- **sheets_service.py** - работа с Google Sheets
- **local_sheets_service.py** - работа с Excel файлами
- **handlers/** - обработчики команд

### ⚙️ Конфигурация хостинга:
- **requirements.txt** - список зависимостей Python
- **Procfile** - команда запуска для хостинга
- **runtime.txt** - версия Python (3.11)
- **.env.example** - пример настроек (НЕ редактируйте, это шаблон!)
- **.gitignore** - защита конфиденциальных файлов

### 📖 Документация:
- **START_HERE.md** ← вы здесь
- **DEPLOY_INSTRUCTION.md** - полная инструкция ⭐
- **QUICK_START.md** - быстрый старт
- **FAQ.md** - вопросы и ответы
- **CHECKLIST.md** - чеклист готовности к деплою
- **CHANGELOG.md** - история изменений
- **README_DEPLOY.md** - краткое описание
