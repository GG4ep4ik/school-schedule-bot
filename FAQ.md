# ❓ ЧАСТЫЕ ВОПРОСЫ (FAQ)

## Общие вопросы

### В: Сколько стоит хостинг бота?

О: Зависит от платформы:
- **BotHost** - от бесплатного до $5-10/мес
- **Railway** - $5/мес (500 часов бесплатно)
- **Render** - бесплатный tier доступен
- **VPS** - от $5/мес (полный контроль)

### В: Можно ли запустить бота бесплатно?

О: Да! Многие платформы предлагают бесплатные тарифы:
- Railway - 500 часов/мес бесплатно
- Render - бесплатный tier с ограничениями
- Pythonanywhere - бесплатный аккаунт

Ограничения: могут засыпать при неактивности, лимиты памяти/CPU.

### В: Что лучше - Google Sheets или Excel файл?

О: 

**Google Sheets:**
- ✅ Можно редактировать откуда угодно
- ✅ Автоматическое обновление
- ✅ Совместная работа
- ❌ Требует настройки API
- ❌ Лимиты запросов

**Excel файл:**
- ✅ Проще настроить
- ✅ Нет лимитов API
- ✅ Работает офлайн
- ❌ Нужно загружать на хостинг при изменениях
- ❌ Нельзя редактировать "на лету"

**Рекомендация**: Начните с Excel, потом переключитесь на Google Sheets.

### В: Как часто проверяются изменения?

О: По умолчанию каждые 5 минут (переменная `CHECK_INTERVAL_MINUTES`).
- Меньше 5 минут - риск превысить лимиты API
- Больше 10 минут - задержка уведомлений

### В: Сколько пользователей может использовать бота?

О: Практически неограниченно. Ограничения:
- Лимиты хостинга (память, CPU)
- Лимиты Google Sheets API (если используете)
- Для школы (100-500 учеников) - хватит любого платного тарифа

## Технические вопросы

### В: Бот не запускается. Что делать?

О: 
1. Проверьте логи - там будет причина
2. Убедитесь, что все переменные окружения настроены
3. Проверьте правильность токена бота
4. Если используете Google Sheets - проверьте доступ Service Account

Подробнее → раздел "Решение проблем" в DEPLOY_INSTRUCTION.md

### В: Как обновить бота после изменений в коде?

О:

**Способ 1 (через GitHub):**
1. Закоммитьте изменения в Git
2. Запушьте в репозиторий
3. BotHost автоматически обновит бота

**Способ 2 (через File Manager):**
1. Откройте File Manager
2. Загрузите изменённые файлы (перезапишут старые)
3. Перезапустите бота

### В: База данных обнуляется при перезапуске. Почему?

О: Некоторые хостинги используют временную файловую систему (ephemeral storage).

**Решение:**
- Подключите Persistent Storage/Volume (если доступно)
- Или используйте хостинг с постоянным хранилищем (Railway, VPS)

### В: Как посмотреть логи бота?

О:
1. Зайдите в панель BotHost
2. Откройте ваш проект
3. Найдите раздел "Logs" или "Логи"
4. Логи обновляются в реальном времени

### В: Можно ли добавить несколько школ/расписаний?

О: Да, но потребуются изменения в коде:
- Добавить выбор школы при `/start`
- Хранить несколько SPREADSHEET_ID
- Изменить логику получения расписания

Это для продвинутых пользователей.

## Google Sheets

### В: Где взять credentials.json?

О: 
1. Google Cloud Console → APIs & Services → Credentials
2. Create Credentials → Service Account
3. Keys → Add Key → Create new key → JSON
4. Файл скачается автоматически

Подробная инструкция → Этап 1, пункт 2 в DEPLOY_INSTRUCTION.md

### В: Service Account не видит таблицу. Что делать?

О:
1. Откройте Google Таблицу
2. Нажмите "Share" (Поделиться)
3. Добавьте email сервисного аккаунта (из credentials.json)
4. Права: "Viewer" (Читатель)
5. Снимите галочку "Notify people"

### В: Превышен лимит запросов Google API. Что делать?

О:
1. Увеличьте `CHECK_INTERVAL_MINUTES` до 10-15
2. Проверьте, нет ли лишних запросов в коде
3. Или перейдите на Excel файл

Лимиты Google Sheets API:
- 100 запросов на 100 секунд на пользователя
- 500 запросов на 100 секунд на проект

### В: Можно ли использовать несколько таблиц?

О: Да, но нужно изменить код:
- Хранить массив SPREADSHEET_ID
- Добавить логику выбора таблицы
- Или объединить всё в одну таблицу с несколькими листами

## Безопасность

### В: Безопасно ли хранить credentials.json на хостинге?

О: 
- Не загружайте в публичный GitHub репозиторий
- На BotHost - безопасно (файлы приватные)
- Ещё безопаснее - через переменные окружения

**Рекомендация**: используйте .gitignore для credentials.json

### В: Кто-то может увидеть мой токен бота?

О: Если вы:
- Не публикуете его в открытых репозиториях
- Не делитесь скриншотами с токеном
- Используете приватный репозиторий на GitHub

То токен в безопасности.

**Если токен утёк:**
1. Откройте @BotFather
2. /mybots → выберите бота → Revoke Token
3. Получите новый токен
4. Обновите на хостинге

### В: Может ли бот удалить мои данные?

О: Нет. Бот имеет только права "Viewer" (чтение) к Google Таблице. Он не может:
- Изменять расписание
- Удалять данные
- Редактировать таблицу

## Функциональность

### В: Как добавить новый класс?

О:
1. Добавьте столбец с классом в Google Таблице
2. Бот автоматически увидит новый класс при следующей проверке
3. Пользователи смогут выбрать его через `/setclass`

### В: Можно ли отключить уведомления об изменениях?

О: Нет встроенной функции, но можно:
1. Установить очень большой `CHECK_INTERVAL_MINUTES` (например, 1440 = раз в день)
2. Или закомментировать код мониторинга в `bot.py`

### В: Как добавить домашние задания?

О: Требует изменений в коде:
1. Создать новый лист "Домашние задания" в таблице
2. Добавить функцию чтения домашних заданий
3. Добавить кнопку в меню
4. Добавить обработчик команды

Это для продвинутых пользователей.

### В: Бот может работать в групповых чатах?

О: Да, но нужно:
1. @BotFather → /mybots → выберите бота → Group Privacy → Disable
2. Добавить бота в группу
3. Дать права администратора (если нужно)

Бот будет отвечать на команды в группе.

## Обновления и поддержка

### В: Как обновить версию библиотеки (например, aiogram)?

О:
1. Откройте `requirements.txt`
2. Измените версию: `aiogram==3.14.0`
3. На хостинге выполните: `pip install -r requirements.txt --upgrade`
4. Перезапустите бота

### В: Где получить помощь, если ничего не помогло?

О:
1. Перечитайте DEPLOY_INSTRUCTION.md
2. Проверьте логи бота
3. Поищите ошибку в Google
4. Документация aiogram: https://docs.aiogram.dev/
5. Telegram Bot API: https://core.telegram.org/bots

## Оптимизация

### В: Как уменьшить потребление памяти?

О:
1. Уменьшите `CHECK_INTERVAL_MINUTES` (меньше проверок = меньше нагрузка)
2. Используйте локальный Excel вместо Google Sheets
3. Очищайте старые данные из БД (нужен код)

### В: Бот работает медленно. Что делать?

О:
1. Проверьте ресурсы хостинга (CPU, память)
2. Оптимизируйте код (кэширование)
3. Увеличьте тарифный план хостинга
4. Или перейдите на более быстрый хостинг (VPS)

### В: Сколько места занимает база данных?

О: Очень мало:
- 1 пользователь ≈ 100 байт
- 1000 пользователей ≈ 100 KB
- 10000 пользователей ≈ 1 MB

Для школы места более чем достаточно.
