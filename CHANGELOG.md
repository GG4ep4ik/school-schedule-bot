# 📝 CHANGELOG - История изменений

## [1.0.0] - 2026-10-20

### Добавлено для деплоя на BotHost
- ✅ Procfile для автоматического запуска
- ✅ runtime.txt с версией Python 3.11
- ✅ .env.example с подробными комментариями
- ✅ Полная документация на русском языке:
  - DEPLOY_INSTRUCTION.md - подробная пошаговая инструкция
  - QUICK_START.md - быстрый старт
  - FAQ.md - часто задаваемые вопросы
  - README_DEPLOY.md - краткое описание
- ✅ Структура папок оптимизирована для хостинга
- ✅ .gitignore для защиты конфиденциальных файлов

### Функции бота
- ✅ Выбор класса и сохранение настроек
- ✅ Расписание на завтра (автоопределение учебного дня)
- ✅ Расписание на конкретный день недели
- ✅ Мониторинг изменений с уведомлениями
- ✅ Работа с Google Sheets API
- ✅ Работа с локальными Excel файлами
- ✅ Асинхронная архитектура (aiogram 3.x)
- ✅ SQLite база данных для пользователей

### Технический стек
- Python 3.11
- aiogram 3.13.1
- gspread 6.1.2
- aiosqlite 0.20.0
- APScheduler 3.10.4
